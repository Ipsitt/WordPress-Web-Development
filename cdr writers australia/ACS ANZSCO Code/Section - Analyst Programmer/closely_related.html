# Brief Description

Analyst programmer is to design, develop, test, maintain and document program code in accordance with user requirements, and system and technical specifications. The major tasks include the designation and the development of the algorithm. An analyst has a major role on analyzing the system and compiling it to find out the problem or any error. They should also have to know about the data structures and various languages like formal and the functioning, this unit also include the object-oriented programming methods. It can be used on a various operating system like UNIX, Linux and etc. Also, this unit includes software engineering and implements various testing method and strategies.

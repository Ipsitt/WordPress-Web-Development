Visa Program Eligibility

Because 135112 is featured on the Core Skills Occupation List (CSOL), its immigration pathways provide excellent access to both permanent residency and priority employer-sponsored streams:

Eligible Visas:

Subclass 186 (Employer Nomination Scheme - Direct Entry PR)
Subclass 482 (Skills in Demand - Core Skills Pathway)
Subclass 190 (Skilled Nominated PR)
Subclass 491 (Skilled Work Regional - State Nominated)
Subclass 494 (Skilled Employer Sponsored Regional)
Subclass 407 (Training Visa)

Ineligible Programs & Streams:

Subclass 189 (Skilled Independent) — Excluded from Strategic Skills list invitations
Subclass 482 (Skills in Demand - Short-Term Stream) — Replaced by Core Skills Pathway
Subclass 489 / Subclass 187 (RSMS) — Closed permanently to all new applications

AIMS Skills Assessment Myths: Six Mistakes that Slow Down Applications

Myth

Membership will do for migration.

No. AIMS membership cannot be used for migration purposes, although you can apply for membership alongside your assessment.

Myth

A positive result guarantees a visa.

It does not. AIMS cannot give visa advice, and a skills assessment is only one part of a skilled visa application.

Myth

Any science degree qualifies me as an MLS.

Not automatically. Only an AIMS accredited degree skips the exam. Other degrees follow a document assessment and a professional examination.

Myth

Research experience counts the same as lab work.

No. Only experience in a recognised medical pathology laboratory after your degree counts, and research-only employment is not favourably considered.

Myth

I can write my own translations.

Not accepted. AIMS requires a certified translation, and applicant-prepared translations are rejected.

Myth

I can add new evidence any time.

Only some. Amendments cover evidence from before the original assessment. Later achievements need a new application.

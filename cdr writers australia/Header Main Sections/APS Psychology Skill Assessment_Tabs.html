APS Application Format & Requirements

The APS assessment process generally involves reviewing:

Eligibility Overview

  • Recognized psychology qualification
  • Comparable Australian psychology sequence
  • Supervised practice requirements
  • English language competency (if applicable)
  • Proper documentation format
We provide guidance to help ensure your documents are properly structured and aligned with APS requirements.

Key Documents Typically Required

  • Psychology degree certificates
  • Academic transcripts
  • Detailed course syllabus (if required)
  • Internship / supervised practice evidence
  • Employment reference letters (if applicable)
  • Resume/CV
  • Identity documents

VETASSESS Application Format & Requirements

The VETASSESS assessment process generally involves reviewing:

Eligibility Checklist

  • Correct occupation selection
  • Relevant qualification level
  • Post-qualification employment experience
  • Employment roles matching ANZSCO description
  • Proper documentation format
We provide guidance to ensure your documentation aligns with the correct occupation category requirements.

Key Documents Typically Required

  • Academic qualification certificates
  • Academic transcripts
  • Employment reference letters
  • Payslips / tax documents (if required)
  • Resume/CV
  • Identity documents
We provide guidance to ensure your documentation aligns with the correct occupation category requirements.
